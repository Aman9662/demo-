Core Features

🎯

Geo-Targeted Danger Mapping

Parses government alerts to render a precise 'Red Zone' polygon instead of generic text warnings.

⚡

Offline-First Resilience

A PWA silently caches maps. If connectivity drops, the app remains fully visible and functional without internet.

🗺️

Avoidance Routing

Calculates escape routes to nearest shelters, refusing to cross danger polygons.

📡

Dual-Mode Triage & SMS Fallback

Submit emergency status via HTTP when online, or gracefully degrade to invisible SMS pings offline.

📊

Responder Authority Dashboard

A real-time command center displaying the hazard map and live color-coded statuses of citizens.
